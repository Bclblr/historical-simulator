# Historian Interpretations

Milestone 62 keeps historiographical interpretation separate from historical-event facts.

A HistorianInterpretation records the event, historian name, a concise thesis and citations. Every selected citation must exist and target the same event. Source metadata is resolved through SourceDisplay.

An interpretation is an attributed scholarly argument, not a HistoricalEvent and not a historical fact. The model does not promote a historian's thesis into the HISTORY evidence layer.
