# Institution Hierarchy

Milestone 49 adds explicit superior/subordinate links between institutions and, optionally, roles.

A hierarchy link records a superior institution/role, subordinate institution/role and an authored subject or scope. Institution-only links use null role IDs.

The hierarchy is explicit and directional. The engine does not infer rank from titles, institution names, prestige or relationship/influence values.

This model describes structural simulation relationships only. It does not automatically grant an authority action: InstitutionalAuthorityGrant remains the source of permitted actions. Likewise, bureaucratic influence and institution relationships remain separate systems.

Historical content packs must source concrete hierarchy claims when they are presented as historical facts. Later position, order/request and institutional consequence milestones can build on these links.
