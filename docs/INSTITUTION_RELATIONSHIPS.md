# Institution Relationships

Milestone 47 adds directional relationships between institutions.

Each relationship has a source institution, target institution, semantic kind, simulation influence value and optional authored note.

Relationship kinds are COOPERATIVE, COMPETITIVE, DEPENDENT, SUPERVISORY, NEUTRAL and OTHER.

The influence value is bounded from -100 to 100 and represents a simulation variable. It is not a historical truth score, moral judgment or automatic measure of political power.

Relationships are directional. A source-to-target relationship does not automatically create or imply the reverse relationship.

The engine does not infer historical relationships from institution names or roles. Historical content packs must explicitly author and source relationships that are presented as historical facts. Later bureaucratic influence, hierarchy, conflict and institutional consequence systems can build on this model.
