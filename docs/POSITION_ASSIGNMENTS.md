# Position Assignments

Milestone 50 separates a historical role definition from an assignment of that role within the simulation.

HistoricalRole remains the reusable definition of an office or role. PositionAssignment records an institution, role, optional person, start/end dates and assignment status.

Statuses are PLANNED, ACTIVE and ENDED. Active-date queries require both ACTIVE status and a matching date interval.

The optional person link prepares the model for institutional characters without requiring every position to be occupied immediately.

An assignment does not automatically create authority, hierarchy or bureaucratic influence. Those remain separate systems.

For historical content, named officeholders and dates must be supported by sources when presented as historical facts. Counterfactual appointments must remain clearly separated from historical records.
